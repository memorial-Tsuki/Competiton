# 冻结C模型演示

唯一模型为rolling_hybrid，主种子20260923、LR权重25%，不重新拟合。此目录包括推理所需项目文件，但不包括Python解释器和安装好的第三方库；不包含重训输入。完整来源和依赖版本见根目录最终版本说明。

在本目录运行：

```text
python src/predict.py examples/pure_limit.json
python src/predict.py examples/new_debt.json
python src/predict.py examples/new_ordinary_dpd.json
python src/predict.py examples/new_joint_dpd.json
python src/predict.py examples/saturated_but_worsening.json
```

原训练依赖在原训练环境_requirements.txt。本轮实际数值环境在本轮已核验_requirements.txt。原模型由scikit-learn1.9.1保存，本轮1.8.0加载有版本警告；记录范围内的概率重放一致，不保证所有环境或所有输入兼容。需要迁移时优先恢复原依赖后验证，不能直接把单一joblib移走而丢掉自定义类与输入范围。

| 示例 | 输入变化 | 本轮核验结果，约值 |
| --- | --- | --- |
| pure_limit | 当前额度63万→94.5万，行为不变 | 参考分575.38不变；实时分比参考分高24.18 |
| new_debt | 只增加余额与支用，不改额度 | 参考分575.38→538.79，下降36.60 |
| new_ordinary_dpd | 只新增普通逾期30天 | 参考分575.38→569.58；要求复核 |
| new_joint_dpd | 两个当前DPD均增加30天 | 输出模型结果并要求复核 |
| saturated_but_worsening | 普通DPD从30→60天 | 参考分569.58持平；仍要求复核 |

这是单个公开记录上的接口演示，事件日期为人工构造。其降分不能代表整体平均；不要把仅负债示例说成同时提额。提额+负债的全体情景结果在主报告第4-5页及统一核心结果明细中。

pd为模型估计的当前申请风险概率，score越高表示模型风险越低。risk_component_points为同参考下行为变化分量，mechanical_limit_component_points为当前实时与参考分的差，二者加和为total_change_points。分解是计算路径，不是因果效应。

requires_review与review_reasons是业务复核提示；分数持平不能取消逾期复核。当前原型没有实现银行事件认证、账户服务、自动到期续审或完整跨版本桥接，不执行审批。examples中的*_output.json是原包历史输出；本轮输出保存在上级本轮核验目录，分开保留。
