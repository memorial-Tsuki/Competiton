# 衡信 · 信用风险评分工作台

赛题一配套的**本地信用评分界面**。纯本机运行，不联网、不上传任何数据。

冻结模型 `rolling_hybrid`（参考额度锚定的单调梯度提升树 + 带符号约束的窗口逾期逻辑回归，0.75 / 0.25 混合后校准）在本机加载并推理，界面只负责输入校验、结果展示与情景推演，**不训练、不修改模型**。

> 本仓库只包含评分界面。论文、数据集、训练代码与实验记录在配套仓库 **赛题一_研究资料**。

## 快速开始

### 方式一：双击启动（Windows）

双击 `启动信用评分网页.cmd`。脚本会自动在目录内查找 `app.py`，调用本机 Miniconda 的 Python 启动服务，并用默认浏览器打开页面。

运行窗口必须保持开启；关闭窗口即停止服务。

若未安装 Miniconda，请改用方式二。

### 方式二：命令行

```bash
python -m pip install -r requirements.txt
python app.py --no-browser --port 18765
```

终端会打印实际监听地址，形如 `http://127.0.0.1:18765`。端口被占用时程序会**自动改用空闲端口**，请以打印出的地址为准，不一定始终是 18765。

浏览器打开该地址即可。

### 启动自检

```bash
python app.py --self-test
```

载入模型并核对 `model_runtime/examples/` 中 5 组案例的保存结果，全部通过则退出，不占用端口。不一致会直接报错，用于确认运行环境与训练环境一致。

```bash
pytest tests/
```

## 界面流程

三层结构：**封面** → **输入** → **输出与简要分析**。

- **输入页**：7 项必填的当前授信与履约信息，以及基础资质、历史信用卡行为、历史申请与分期、外部评分四类选填信息。
- **提交后**：显示本地计算进度条，随即进入输出页。
- **输出页**：展示评分、风险概率、等级、完整度提示与复核原因，可继续进入**情景推演**，比较提额、新增借款或逾期变化后的结果。

### 冷启动入口

界面提供「**新客户 / 无历史**」模式，仅需填写收入与拟定首次授信额度。

- 余额、支用、付款和两类逾期按「尚未发生」处理为 0；
- 信用卡历史、申请历史与分期历史保持**缺失**，不以 0 代替未知；
- 结果强制附带人工复核提示。

冻结模型的训练队列包含已有活跃卡记录的客户，因此冷启动输出**仅为研究性估计**，不构成首授审批或额度建议。

## 接口

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/` | 工作台页面 |
| GET | `/api/config` | 字段定义、情景定义、会话 token |
| GET | `/api/health` | 健康检查，返回模型 SHA-256 |
| GET | `/api/example/<id>` | 读取内置示例 |
| POST | `/api/score` | 评分，需 `X-Score-Token` 头，请求体上限 64 KB |

安全设置：仅监听 `127.0.0.1`、校验 Host 与 Origin、会话 token、CSP 限制为 `'self'`、响应 `no-store`、不记录输入。

## 输入口径

- `DAYS_BIRTH`、`DAYS_EMPLOYED` 在界面填**年数（正数）**，系统内部乘 −365.25 换算为原始相对天数。
- `prev_latest_day` 填**正数天数**（如 180 表示 180 天前），内部转为负值。
- 金额沿用原始数据单位，不推断币种，请勿混用月收入与其他收入周期。
- 历史类字段**未知就留空**，系统沿用模型训练时的缺失处理，不会替你编造客户信息。

## 免责声明

本界面是学术研究工具的展示层：

- 输出是对公开数据当前申请 `TARGET` 标签的**研究性估计**，不是银行征信分，也不是「未来一年真实违约概率」；
- 参考额度锚定会使得纯提额情景下评分不变，这是设计性质而非缺陷；
- 不构成自动授信、自动审批或额度建议；
- 冷启动结果未在独立首授样本上验证。

模型、数据口径与完整限制说明请见配套仓库的论文与算法说明。
