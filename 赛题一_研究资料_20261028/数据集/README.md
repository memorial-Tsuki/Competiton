# 数据集

最终 C 组窗口峰值混合模型使用的**清洗后、冻结输入**，不是历史 UCI 版本或早期融合版的划分文件。

| 文件 | 体积 | 内容 |
|---|---|---|
| `cohort.csv` | 12 MB | 38,934 名客户的一行一客户建模样本，重训与推理的主样本 |
| `repeated_splits.csv` | 7.4 MB | 5 个重复划分，用于稳定性重复实验 |
| `split_manifest.csv` | 1.3 MB | 种子 20260923 的训练 / 验证 / 校准 / 测试四角色划分 |
| `observed_transitions.csv` | 0.96 MB | 观察到的两期逾期变化记录，用于逾期响应的观察性核验 |
| `feature_dictionary.csv` | 小 | 清洗特征及现实业务含义字典 |
| `input_manifest.json` | 小 | 冻结输入、原始来源与 SHA-256 记录 |

## 关于原始数据

原始公开数据来自 Kaggle **Home Credit Default Risk** 竞赛数据，合计约 1.7 GB 且受上游发布条款约束，因此不纳入本仓库。需要完整清洗流程时，先从数据发布方获取原始 CSV，再运行 `核心代码/模型实验/src/prepare_study.py`。

本目录提供的 `cohort.csv` 是已完成清洗的可复现研究输入。

## 口径提示

- 标签 `TARGET` 表示**当前申请的还款困难标签**，不是按月信用卡违约标签。
- 样本仅覆盖在月 −1 存在有效活跃信用卡记录的客户。
- 所有金额沿用原始数据单位，不推断币种。

> 大文件提示：GitHub 网页对超过约 10 MB 的文件不提供在线预览，`cohort.csv` 和 `repeated_splits.csv` 需要克隆后本地打开。

完整说明见仓库根目录 [数据集说明.md](../数据集说明.md)。
