## 论文与最终模型

论文为 7 页 PDF，符合正文不超过 8 页的比赛限制。

最终方案是 C 组 `rolling_hybrid`：参考额度锚定的单调梯度提升树与带符号约束的窗口逾期逻辑回归按 **0.75 / 0.25** 混合，再在独立校准集上校准。

最终测试集角色规模：训练 23,364、验证 5,839、校准 3,893、测试 5,838（其中正类 582）。

> 结果只能用于本研究的当前申请标签任务，**不能**与不同数据集、不同客户划分或不同标签任务的 AUC 直接排名比较。

模型、数据口径、性能证据和限制，以论文及 [核心算法说明](核心算法说明/核心算法说明.md) 为准。

## 重训与复现

为避免重复保存数据，模型实验目录不复制 `data/`。先在仓库根目录执行：

```powershell
Copy-Item -Recurse .\数据集 .\核心代码\模型实验\data
cd 核心代码\模型实验
python -m pip install -r ..\..\requirements.txt
python src\run_experiment.py
```

完整的空目录重训与一致性比对使用 `src/reproduce.py`：基于清洗后冻结队列、预先冻结的基线模型和预设实验协议重新训练候选模型，不重新清洗 1.7 GB 原始 CSV。

运行会在 `核心代码/模型实验/models/` 和 `results/` 写入本地结果，这两个目录已被 `.gitignore` 排除。

## 首次授信额度代理研究

`核心代码/模型实验/src/first_limit_proxy.py` 使用梯度提升回归和保形预测区间，尝试以申请时可见字段预测「首次**可观测**信用卡额度代理」。运行时须另行提供上游 `credit_card_balance.csv`：

```powershell
cd 核心代码\模型实验
python src\first_limit_proxy.py --raw-credit-card <credit_card_balance.csv 的本地路径>
```

结果保存在 `核心代码/模型实验/首次可观测额度实验结果/`。

主测试集 MAE 为 133,266，R² 为 −0.039，较全局中位数基线仅有很小改善；80% 保形区间实际覆盖 81.4%，但平均区间宽度为 368,122。因此该模块当前只能作为**数据可得性诊断与不确定性输出接口**，不能作为自动首授额度策略。

未采用 GAN：生成模型不能为缺失的真实首授标签提供可验证的监督信号。

## 研究边界

本项目证明的是在给定输入与固定参考额度条件下的**风险排序、校准和响应性质**。

- 不构成自动授信系统，也不识别真实提额的因果效应；
- 当前验证为随机客户划分和重复划分，**不是时间外验证**；
- 30 天以上逾期被封顶，逾期恢复的滞后未被充分验证；
- B、C 两组是在 A/B 验证响应失败后加入的序贯设计，不是从全新独立数据中发现的结论；
- 冷启动（首次授信）输出未在独立首授样本上验证。
