## 常见问题

**`git push` 报 `failed to push some refs`**
远程已有内容（建库时勾选了初始化文件）。先合并再推：

```bash
git pull --rebase origin main
git push -u origin main
```

**`git add .` 后文件数明显偏多**
`.gitignore` 未生效。用 `git status --short | wc -l` 核对，A 应为 36、B 应为 72。

**两个仓库搞混了**
用 `git remote -v` 查看当前目录关联的是哪个远程地址。

**中文文件名显示成 `\344\275\240`**
`git config core.quotepath false` 后重新执行 `git status`。

## 完整性校验

每个仓库根目录都有 `文件清单_SHA256.json`，克隆后可核对：

```bash
python -c "
import json,hashlib
from pathlib import Path
d=json.load(open('文件清单_SHA256.json',encoding='utf-8'))
bad=[]
for f in d['files']:
    p=Path(f['path'])
    if not p.exists(): bad.append(('缺失',f['path'])); continue
    if hashlib.sha256(p.read_bytes()).hexdigest()!=f['sha256']: bad.append(('不一致',f['path']))
print('通过' if not bad else bad)
"
```
