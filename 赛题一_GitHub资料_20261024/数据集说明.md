# 数据集说明

`数据集/` 保存的是最终 C 组窗口峰值混合模型所用的**清洗后、冻结输入**，而非历史 UCI 版本或早期融合版的随机划分文件。

| 文件 | 内容 | 用途 |
|---|---|---|
| `cohort.csv` | 38,934 名客户的一行一客户建模样本 | 重训与推理的主样本 |
| `split_manifest.csv` | 种子 20260923 的训练、验证、校准、测试四角色划分 | 最终模型选择与独立测试 |
| `repeated_splits.csv` | 5 个重复划分 | 稳定性重复实验 |
| `observed_transitions.csv` | 观察到的两期逾期变化记录 | 逾期响应的观察性核验 |
| `feature_dictionary.csv` | 清洗特征及现实业务含义字典 | 解释和字段核对 |
| `input_manifest.json` | 冻结输入、原始来源与 SHA-256 记录 | 完整性校验 |

原始公开数据来自 Kaggle 的 Home Credit Default Risk 竞赛数据。原始 CSV 合计约 1.7 GB，且包含上游发布条款；因此不复制入本仓库。请从数据发布方获得原始数据后，再使用 `核心代码/模型实验/src/prepare_study.py` 完整清洗。这里提供的 `cohort.csv` 是已完成清洗的可复现研究输入。

标签 `TARGET` 表示当前申请的还款困难标签，不是按月信用卡违约标签。样本仅覆盖在月 -1 存在有效活跃信用卡记录的客户；所有金额沿用原始数据单位，不推断币种。该设计没有时间外验证，也不能识别真实提额的因果效应。
