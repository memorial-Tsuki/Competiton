# 赛题一：基于参考额度锚定与窗口峰值混合模型的授信客户风险评分稳定性研究

本仓库整理了赛题一最终论文、最终 C 组模型的清洗后输入数据、核心训练与推理代码、算法说明，以及论文实际使用的全部图片。目标是让审阅者能明确区分最终版本、历史版本与可复现边界。

## 论文与最终模型

论文为 7 页 PDF，符合正文不超过 8 页的比赛限制。最终方案是 C 组 `rolling_hybrid`：参考额度锚定的单调梯度提升树与带符号约束的窗口逾期逻辑回归按 0.75 / 0.25 混合，再在独立校准集上校准。模型、数据口径、性能证据和限制请以论文及 [核心算法说明](核心算法说明/核心算法说明.md) 为准。

最终测试集的角色规模为：训练 23,364、验证 5,839、校准 3,893、测试 5,838（其中正类 582）。结果只能用于本研究的当前申请标签任务，不能与不同数据集、不同客户划分或不同标签任务的 AUC 直接排名比较。

## 数据

`数据集/` 中是最终逾期增强实验使用的清洗后冻结输入，并附有 SHA-256 输入清单。原始 Home Credit Default Risk CSV 未纳入仓库：文件总量约 1.7 GB，且应遵循上游数据发布条款。数据范围、字段、标签和已知限制见 [数据集说明](数据集说明.md)。

## 运行评分界面

建议使用 Python 3.12 和根目录 `requirements.txt` 中的固定版本。

```powershell
python -m pip install -r requirements.txt
cd 核心代码\评分界面
python app.py --self-test
python app.py --no-browser --port 18765
```

最后一条命令会启动本机服务；在浏览器打开终端显示的地址即可。评分界面只加载冻结模型，不训练或修改模型；输入示例在 `核心代码/评分界面/model_runtime/examples/`，自动化校验位于 `核心代码/评分界面/tests/`。

## 重训与复现

为避免重复保存数据，模型实验目录不再复制 `data/`。先在仓库根目录运行：

```powershell
Copy-Item -Recurse .\数据集 .\核心代码\模型实验\data
cd 核心代码\模型实验
python -m pip install -r ..\..\requirements.txt
python src\run_experiment.py
```

完整的空目录重训与一致性比对使用 `src/reproduce.py`。该脚本会基于清洗后冻结队列、预先冻结的基线模型和预设实验协议重新训练候选模型；它不重新清洗 1.7 GB 原始 CSV。运行会在 `核心代码/模型实验/models/` 和 `results/` 写入本地结果，已被 `.gitignore` 排除。

## 图片命名与来源

图片文件名均以“`程序输出_程序名_内容`”命名，三张图均由仓库代码使用项目冻结结果生成，没有外部图片。每张图的来源、输入和论文位置见 [图片来源说明](图片来源说明.md)。

## 研究边界

本项目证明的是在给定输入与固定参考额度条件下的风险排序、校准和响应性质。它不构成自动授信系统，也不识别真实提额的因果效应。当前验证为随机客户划分和重复划分，不是时间外验证；30 天以上逾期被封顶，逾期恢复的滞后也未被充分验证。
