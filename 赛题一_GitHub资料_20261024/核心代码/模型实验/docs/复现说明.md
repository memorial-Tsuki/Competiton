# 本轮复现与解释记录

本轮以已冻结的 38,934 人队列和上一阶段三个方法的六套基准为输入。原始 CSV 清洗不是本轮重新训练的对象；最近两月同卡集合的 DPD 变化已由 prepare_study.py 直接从原卡月 CSV 构造并与当前队列交叉核对。输入清单同时保留该原始 CSV 的 SHA256。

reproduce.py 在同级 tmp 新建目录，仅复制冻结输入、三个协议和数值源码，不复制本轮训练结果或候选模型。依次训练 A、B、C、执行统一诊断，重新获得 54 个新模型并比较 34 项数值输出。容差为 rtol=1e-10、atol=1e-12；JSON 中数值同样比较。

模型重放逐个载入 54 个新文件和 18 个冻结基准，核对保留的测试、情景和观察变化预测，以及校准前后的性能。独立主指标使用秩和、累计计数、并列名额的期望公式核对。16 项契约检查允许某些约束系数学成零，避免把预设正系数的“成功”当作训练证据。

A/B/C 使用相同六个已知划分，B/C 是在 A/B 验证响应失败后加入的序贯设计。普通逾期响应不是从全新独立数据发现；C 的窗口结构把历史逾期的学习信号延伸到当前月，是一项可解释但需要外部验证的假设。主模型在窗口内的改善事件可能持平，严重逾期超过 30 天的区分也被压缩。

为统一机器读取格式，B 组选参记录的协议哈希键名规范为 additional_protocol_sha256，原哈希值、选择及数值未改。独立重训已按统一格式比较。输入哈希验证并不证明原始数据的发布者身份或许可；本包沿用用户提供资料。

报告和图表只从保留结果与明确窗口公式生成，不用绘图修饰虚构响应曲线。图 2 的格内天数是特征定义示意，不是实际违约率；其余实验图来自结果表。视觉审阅与模型数值指纹分别绑定 PDF 和数值文件，文档布局修改不要求重新训练模型，模型或数值代码修改则必须重新核查。
