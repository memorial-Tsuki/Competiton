A 组主划分两种约束 LR 都将普通 DPD 系数学成 0、容忍 DPD 系数为正；封顶和符号约束本身不能恢复普通 DPD 响应。增加共享参数对照以检验“两个逾期字段不能互相抵消或完全切断其中一路”的结构假设。
