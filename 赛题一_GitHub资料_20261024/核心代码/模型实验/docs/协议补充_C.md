# C 组：统一当前与历史逾期窗口

2026-09-28，在 C 组训练前固定。A/B 组的主划分验证门槛均失败：即使共享两个当前字段，新增普通逾期的系数仍为零。已查看验证选择与相应系数，尚未读取 A/B 新测试性能或情景输出。保留全部失败试验；本研究已发生序贯特征设计，不能以一次预注册、全新盲测或无选择偏差描述。

旧模型使用历史最大逾期，但没有采用当前两个逾期字段；普通 LR 的历史最大逾期系数为正。C 组检验一种不同时间汇总假设：把最近可见六个月（历史 -6 到 -2 月和当前 -1 月）的最严重普通逾期纳入同一窗口，使当前月不会因被分成另一路而失去响应。

构造 rolling = log(1+min(max(hist_max_dpd,dpd,dpd_def),30))。历史缺失时仅使用已知当前两项，另加 hist_dpd_missing 指示，不把缺失默认为历史零逾期。删除原两个当前 DPD 项及历史最大 DPD 项；其他变量保留。当前数据容忍 DPD 不超过普通 DPD，保留 max 中的容忍字段为输入一致性和通用性表达。rolling 系数非负、允许为零；沿用其余 7 项行为方向，不强制正系数。

该结构假设是“最近窗口最大逾期”：当前逾期没有超过既有历史峰值时可以不加分；超过 30 天后可以饱和。不能要求此类客户每加一天都变动，也不能把峰值未刷新解释为新增逾期无害。新增/恶化和 ≥30 天仍须业务复核。

新增 rolling_lr、rolling_hybrid。L2、α、验证 AUC/Brier 容忍度、当前双零客户普通 +30 的 ≥99% 正响应及中位增幅 ≥0.001 门槛、校准和六个冻结划分均沿用 A 组。当前双零但历史峰值已达 30 的客户可能使 99% 门槛失败；不为此调整阈值或删除这些客户。所有失败分支照常保留。

本组为本轮最后一批候选。之后统一审阅 A/B/C 测试、实际观察变化、五次划分和不确定性；不根据它们继续改特征或调门槛。当前申请标签只校验当前预测，不证明窗口内某次逾期造成的未来违约效果。
